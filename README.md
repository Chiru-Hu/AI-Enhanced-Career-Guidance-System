# 🎓 AI-Enhanced Career Guidance System

## 📌 Overview
The AI-Enhanced Career Guidance System is a web application that helps students identify suitable career paths based on their skills, interests, and academic background. It provides personalized career recommendations using Machine Learning.

---

## ✨ Features
- Student Registration & Login
- Career Recommendation
- Skill Gap Analysis
- Course Recommendations
- Resume Analysis
- Admin Dashboard
- Secure Authentication

---

## 🛠 Technologies Used
- Python

- Machine Learning

- Bootstrap

## ⚙️ How It Works

1. User registers and logs in.
2. User enters skills and interests.
3. Machine Learning analyzes the profile.
4. The system recommends suitable careers.
5. Users can identify skill gaps and explore recommended courses.
