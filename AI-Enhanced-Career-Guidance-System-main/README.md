# 📖 Project Overview

The **AI-Enhanced Career Guidance System for Personalized Career Pathway** is a web-based platform that helps students discover suitable career paths using AI-driven assessments and profile analysis. The system provides personalized career recommendations, career reports, job suggestions, and enables collaboration between students, parents, counselors, and administrators.

Built using **Django**, the application integrates career assessments, report generation, and role-based dashboards into a single platform.

# ⚙️ Installation

```bash
git clone https://github.com/YOUR_USERNAME/AI-Enhanced-Career-Guidance-System.git

cd AI-Enhanced-Career-Guidance-System

conda create -n career python=3.12
conda activate career

pip install -r requirements.txt

python manage.py migrate
python manage.py runserver

In Virtual_App/views.py -- you must add the gemini api key of your own by which questions in project will work properly.
```
